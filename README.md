# The World Today — Wednesday 25 November 2026

One image that sums up the world's news of Wednesday 25 November 2026,
drawn entirely from code.

`main.ts` (Node 22, standard library only) renders a 1024x1024 front page
to `/output/entry.png`: the Shenzhou-24 launch carrying the first foreign
astronaut to China's Tiangong station; Kyiv confirming its strikes on
Russian ships in the Gulf of Finland and off Benghazi; the Russian strike
on Odesa; the Australia–Solomon Islands security pact; Beijing's probe of
Shanghai party chief Chen Jining; the US pause on joint operations with
Ecuador; Australia's apology to LGBTQ veterans; markets waiting on US
inflation data; plus the day's briefs. Every story was first reported on
25 November 2026 (Reuters, RFE/RL). No network, no downloaded assets —
the PNG encoder, the bitmap font and every icon are in `main.ts`, so two
runs write identical bytes.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
